# Freight-forecasting-Model
ML project for Freight shipping rates

Freight Forecasting Model

A Machine Learning project for forecasting freight-related values using historical data. The project explores data preprocessing, exploratory data analysis, model training, model comparison, and selection of the best-performing forecasting model.

Project Overview

Freight forecasting is useful for estimating future freight demand and supporting better planning and decision-making.

In this project, historical freight data is analyzed and different Machine Learning models are trained and evaluated. The models are compared using suitable evaluation metrics, and the best-performing model is selected for forecasting.
